Phase 5 uses the Phase 4 data (ACID attacks, extra genuine platform-like copies, 4 more AI generators: SVD, Mora, Text2Video-Zero, Pika). Each clip: first 5 (or 10) I-frames, 480 x 480 luma.

Protocol. Realistic protocol, 5-fold cross-validation grouped by camera model: every test camera is unseen in training; validation uses other camera models. 3. Phase 5 results (final framework)

Phase 5 changes (same data and splits as Phase 4): 1 processing-matched training weights; 2 reliability-aware stacking; 3 three-zone decision (accept / inconclusive / accuse); 4 camera-calibrated PRNU evidence (the clip's PCE relative to the claimed camera's median over 10 genuine reference videos, never the clip's own source video).

3.8 Tried in Phase 5 and not kept

  • Processing-matched ViT (overnight run): genuine CRF-20 re-encodes accepted 58% → 72%, but F1 0.842 → 0.833 (10 frames), so the final framework keeps the Phase 4 ViT.
  • Block-level compression-aware PRNU predictor (Chen et al., 2008): after video compression the block correlation is mostly noise (observed vs. expected r = 0.15); no gain, dropped.
  • Single-threshold inconclusive rule: needed 44% inconclusive for the same false-accusation rate; replaced by the three-zone rule.
