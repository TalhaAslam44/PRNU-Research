\section*{Summary}\begin{itemize}
\item \textbf{Best result on its own test set:} Phase 3 (stacking), macro F1 0.851, AUC 0.941; the conventional PCE rule reaches AUC 0.549. Phase 1's F1 0.852 came from an easier test set with a shortcut (every WhatsApp clip was genuine).
\item \textbf{Same clips:} on the 6,535 clips every phase tested, the PCE rule scores the same in all 5-frame runs (AUC 0.572--0.573), so the comparison is fair. Without the real WhatsApp/YouTube copies, Phase 3 stacking (0.796) beats Phase 1's GRU (0.780).
\item \textbf{Phase 4:} on the Phase 3 test clips, Phase 4 stacking scores 0.824 vs.\ 0.852 (10 frames: 0.835). The change is uneven (Table~\ref{tab:source}): genuine VISION videos are recognised far more often (68\% $\rightarrow$ 85\%), but genuine ACID re-encodes are now often called manipulated (83\% $\rightarrow$ 61\%): the new ACID attacks went through the same encoder. On the clips every phase tested (VISION and GenVidBench), Phase 4 is the best phase (0.868 vs.\ 0.803). Own, larger test set: F1 0.814 (5 frames), 0.827 (10 frames).
\item \textbf{HVPF-2 (80/20):} same test clips as Phase 3; stacking 0.851 vs.\ 0.852: the split does not change the conclusions.
\end{itemize}

\section{Conclusions}\begin{itemize}
\item Phase 1's high score was a shortcut; Phase 2 made the benchmark honest; Phase 3 is the best and most reliable result and is the one used for the mid-evaluation.
\item Training on 80\% instead of 60\% of the camera models (HVPF-2) changes the results by less than the fold-to-fold spread.
\item Phase 4 adds coverage that Phase 3 lacks (attacks on a second dataset, more generators) and recognises genuine VISION videos much better, but calls more genuine ACID re-encodes manipulated; 10 frames recovers part of the loss and dataset-balanced training does not help. The open problem is separating genuine re-encodes from attacked clips.
\item In every phase the conventional PCE rule stays near AUC 0.55 for genuine vs.\ not genuine, far below the learned models.
\end{itemize}
